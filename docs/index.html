预测窗口Forecast windows

每个窗口读取 14 天历史状态与天气，并拼接未来 7 天天气情景（共 182 维特征），输出未来 7 天 × 4 个状态。窗口以 7 天步长滑动，不跨生育季。

Each window reads 14 days of states and weather plus the next 7 days of weather (182 features), and predicts 7 days × 4 states. Windows slide by 7 days and never cross a season boundary.

历史 14 天（特征）14-day history (features) 未来 7 天（目标）Next 7 days (targets)

按年份隔离Split by year

先按年份划分完整生育季，再生成窗口；每年 2 个地点 × 2 个品种。

Whole seasons are assigned to a split by year before windowing; each year has 2 sites × 2 cultivars.

  • 标准化参数仅由训练集拟合
  • Scaling is fit on the training set only
  • 未来状态只用于监督和评分，不进入特征
  • Future states are targets only, never features
  • 年份重叠的配置在运行前被拒绝
  • Configs with overlapping years are rejected up front

RICESIM-ORYZA

外部引擎接入External engine integration

通过独立进程调用 RICESIM，将逐日日表转换为与 WOFOST 相同的统一状态表。可执行程序和原生输入由用户提供，每个资产记录来源与 SHA-256。

RICESIM runs as a separate process; its daily table is converted into the same state schema as WOFOST. You supply the executable and native inputs, and every asset is recorded with its source and SHA-256.

1 · prepare
rice-growth oryza-prepare --output DIR

创建运行目录：run.yaml、assets.yaml、CONTROL.DAT.in 模板，以及明确列出的缺项清单。已有目录不会被覆盖。

Scaffolds a workspace with run.yaml, assets.yaml, a CONTROL.DAT.in template and an explicit list of missing materials. Never overwrites an existing directory.

2 · check
rice-growth oryza-check --config run.yaml

检查配置、输入引用、程序权限、资产哈希与输出冲突；FILEI* 路径不超过 80 字符。通过返回 0，有缺项返回 1。

Checks the config, input references, executable permissions, asset hashes and output collisions, and that FILEI* paths fit in 80 characters. Exits 0 when ready, 1 when something is missing.

3 · run
rice-growth oryza-run --config run.yaml

运行引擎并按 mapping 转换日表；保留 stdout/stderr 日志，超时也保留已捕获内容。

Runs the engine and converts the daily table through the column mapping. stdout/stderr logs are kept, even on timeout.

日结果校验Daily output validation

  • 日期连续、无重复；支持 ISO 日期或年份 + 年积日
  • Continuous, unique dates; ISO dates or year + day-of-year
  • 状态非负、有限；DVS 单调不减
  • States non-negative and finite; DVS never decreases
  • 非 UTF-8 输出与 “-” 占位值被拒绝，并保留日志
  • Non-UTF-8 output and “-” placeholders are rejected with logs kept
  • 映射须人工确认 mapping_verified: true
  • Mappings must be confirmed with mapping_verified: true

当前状态Status

接口、模板与校验已完成并有测试覆盖。锁定的上游未附完整构建配置及案例输入（如 xl753.crp、PADDYIN-AR-LA.DAT），本仓库不提供预编译 RICESIM 程序。

The interface, templates and checks are done and tested. The pinned upstream ships without a full build config or case inputs (e.g. xl753.crp, PADDYIN-AR-LA.DAT), so this repo does not bundle a prebuilt RICESIM binary.

需自备可执行程序与输入Bring your own binary and inputs

Quick start

快速开始Quick start

# Python 3.11, repo root
python3 scripts/bootstrap.py
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
.venv/bin/python -m pip install --no-deps ./external/pcse
.venv/bin/python -m pip install --no-deps -e .

# check the environment, run the demo
.venv/bin/rice-growth doctor
.venv/bin/rice-growth demo \
  --config configs/demo.yaml \
  --output artifacts/run_001

# rebuild this page's data
.venv/bin/python scripts/build_pages.py \
  --run artifacts/run_001
